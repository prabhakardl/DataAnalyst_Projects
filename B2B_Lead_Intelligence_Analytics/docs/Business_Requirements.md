# Business Requirements

## Problem
Business development teams need a repeatable way to identify technology-relevant companies, prioritize prospects, measure outreach and focus resources on high-performing markets.

## Stakeholders
- Business Development Manager
- Sales Manager
- Delivery/Technology Team
- Marketing/Outreach Team
- Management/Leadership

## Questions
1. Which countries generate the most qualified leads?
2. Which industries show the strongest engagement?
3. Which database technologies are most common among prospects?
4. Which campaigns/templates produce the best reply rate?
5. What percentage of discovered leads become qualified?
6. Which high-score leads need follow-up?
7. Which markets should receive more business-development effort?

## Deliverables
- Clean analytical datasets
- MySQL schema
- Python analysis scripts
- Power BI executive dashboard
- KPI and business insight report
